# 🌌 Acerca del proyecto

**CodeRAD** es un toolkit de desarrollo rápido diseñado para crear aplicaciones modernas y reutilizables utilizando Java y Codename One bajo principios MVC (Model-View-Controller).

El framework permite:

- ⚡ Desarrollo rápido de aplicaciones
- 🧩 Componentes reutilizables
- 🎨 Interfaces modernas
- 🏗️ Arquitectura MVC
- 📱 Aplicaciones multiplataforma
- 🔄 UI declarativa
- 🚀 Componentes ricos y extensibles

La plataforma fue desarrollada con enfoque en:

- 🛠️ Productividad
- ⚡ Reutilización
- 🎨 UI avanzada
- 📱 Compatibilidad móvil
- 🧠 Arquitectura limpia
- 🔌 Integración flexible

# 🚀 Configuración del proyecto

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/shannah/CodeRAD
```

---

## 2️⃣ Entrar al proyecto

```bash
cd CodeRAD
```

---

## 3️⃣ Configurar JAVA_HOME

Asegurarse de tener configurado un JDK válido.

---

## 4️⃣ Instalar dependencias

```bash
mvn install
```
